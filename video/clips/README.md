# Clips for the pitch and demo videos

Drop video files here (mp4 or mov). Use these names so the edit picks them up. Any length is fine: the edit trims them. Landscape (16:9) works best; phone recordings in portrait are fine for the Telegram scenes.

| File name | What it shows | Used for |
| --- | --- | --- |
| `telegram.mp4` | **Your screen recording** of a real Telegram group with Pause: someone asks a question without tagging it and Pause answers; `/status`; a payment posted; a hotel or Airbnb search with photos. The most important clip. | Proof Pause is active in the group |
| `telegram-languages.mp4` | Your screen recording asking Pause the same thing in two or three languages (for example English, French, Yoruba or Pidgin) and it answering in each | Languages scene |
| `friends-planning.mp4` | Friends planning together on their phones or around a table | Opening |
| `chasing-money.mp4` | One tired person collecting or counting money, or calling people to pay | The problem |
| `celebration.mp4` | The event happening: a party, reunion, wedding or trip | The payoff |
| `scam-call.mp4` | Someone worried on a phone call or reading a message | Scam protection |
| `city.mp4` | A city skyline or street (Lagos, Las Vegas, London, Accra) | Live web search scene |

Royalty-free sources: Pexels (pexels.com/videos) and Pixabay (pixabay.com/videos) allow free use without credit. Avoid clips with visible brand logos.

When the files are here, run `node video/make-pitch.mjs` (built once the clips arrive).
